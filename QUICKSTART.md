# Quick Start Guide / Gyors útmutató

## English

### Run the Application:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Open two terminals:**

   **Terminal 1 - Start API:**
   ```bash
   npm run dev:api
   ```
   ✅ API running on http://localhost:3001

   **Terminal 2 - Start Web:**
   ```bash
   npm run dev
   ```
   ✅ Web app running on http://localhost:3000

3. **Open browser:**
   Go to http://localhost:3000

---

## Magyar

### Alkalmazás futtatása:

1. **Függőségek telepítése:**
   ```bash
   npm install
   ```

2. **Nyiss két terminált:**

   **1. terminál - API indítása:**
   ```bash
   npm run dev:api
   ```
   ✅ API fut a http://localhost:3001 címen

   **2. terminál - Web indítása:**
   ```bash
   npm run dev
   ```
   ✅ Webalkalmazás fut a http://localhost:3000 címen

3. **Böngésző megnyitása:**
   Menj a http://localhost:3000 címre
